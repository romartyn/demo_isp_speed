# Speed Check CLI

Консольная утилита на TypeScript (Node.js) для замера скорости скачивания файла по HTTP/HTTPS с помощью серии последовательных запросов.

## Особенности реализации
- **Zero-dependencies & Native TypeScript**: используется встроенная поддержка запуска `.ts` в Node.js 22.6+ (`node index.ts`), нативный `fetch`, `AbortController` и `node:perf_hooks` (`performance.now()`). Никаких внешних зависимостей и `node_modules`.
- **Защита от кэширования**: к каждому запросу добавляется заголовок `Cache-Control: no-cache` и уникальный query-параметр `_cb`, чтобы промежуточные прокси/CDN каждый раз честно отдавали тело файла, а не кэшированный ответ.
- **Полная вычитка тела ответа**: скрипт дожидается полной загрузки `response.arrayBuffer()` перед остановкой таймера.

## Требования
- **Node.js** версии `22.6.0` или выше (нативный запуск TypeScript).

## Запуск

Клонируйте репозиторий и запустите скрипт, передав целевой URL первым аргументом:

```bash
git clone <url-вашего-репозитория>
cd speed-check-cli
node index.ts https://wikimedia.org
```

Опционально вторым аргументом можно передать количество запросов (по умолчанию - `10`):

```bash
node --experimental-strip-types index.ts https://wikimedia.org 5
```
Или
```bash
npm start -- https://wikimedia.org 5
```
Флаг `--experimental-strip-types` понадобится, если вы не переключились на версию из `.nvmrc` (`nvm use`) или используете Node.js ниже `22.18.0`.

## Единицы измерения
- **Объём данных**: отображается в человекочитаемом формате (`B`, `KB`, `MB`, `GB` в двоичной системе - `1 MB = 1024 KB`), а также точным числом байт в итоговой сводке.
- **Время запроса**: миллисекунды (`мс`) для отдельных запросов и среднего значения, секунды (`с`) для общего времени теста.
- **Скорость скачивания**: выводится одновременно в двух привычных форматах:
  - **Мбит/с** (мегабиты в секунду, десятичные: `байты * 8 / 1 000 000 / сек`) - стандарт провайдеров и сетевых утилит;
  - **МБ/с** (мегабайты в секунду, двоичные: `байты / 1024 / 1024 / сек`) - реальная скорость записи/скачивания файлов.
